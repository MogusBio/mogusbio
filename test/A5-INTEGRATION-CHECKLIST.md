# A5 本地贯通验收

- 原生同版真实冷链负责材料/制造/持续奖励守恒；页面事件与实际记录适配负责接口衔接，不把两类证据混写。
- 购买、项目、制造、合成已有精确原生结果；A4新增HTTP桥接与浏览器校验器必须用同一实际响应做契约检查，避免宽松stub漏字段。
- 普通质押不等待BIO；上层消费旧实例，只保留历史债权，不重复计未来权重。
- 验收持续推进、补账、领取、完整退出、转让、私有承诺和轮次，无自动准备/签发/广播。
- 费用必须分开销售收入、协议费、LAB销毁、押存和网络费；未报价不能写资金充足。
- 检查十个页面导航、异步失效、默认关闭和本地模型；实际浏览器截图单列。
- 全量Node回归、14份模型冻结与当前源码快照最后生成；不重新部署或改冻结参数。
- 正式钱包网络、独立审计、公网多用户入口和上线属于A6–A11，保持未执行，不以本地验收冒充。
