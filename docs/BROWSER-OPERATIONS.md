# P10.1 本地交易操作层

第四个导航页“链上操作”把原生 SDK 接入本地工作台。它接收 SDK 生成的精确 intent，依次准备未签名交易、检查消息、模拟、请求钱包签名、明确发送，再查询 finalized 业务结果。准备、模拟和钱包签名均不表示交易已经执行。

默认运行 `npm start` 只启用本地模型实验；没有可信发布配置时，交易按钮和钱包连接关闭。当前仓库没有获准的生产部署配置，公开测试身份不能作为生产身份。

## 可信服务端配置

服务端只接受命令行指定的绝对配置路径：

```sh
node apps/server/main.mjs --native-config /absolute/path/native-config.json
```

配置必须精确包含以下四个字段，不得增加私钥或浏览器可变的参数：

```json
{
  "releaseFile": "/absolute/path/approved-release.json",
  "endpoint": "https://your-approved-rpc.example/",
  "stateDirectory": "/absolute/path/private-state",
  "localPublicFixture": false
}
```

这是字段示意，不是可运行的生产配置。releaseFile 必须通过现有源码、政策、ABI 与部署输入准入。stateDirectory 必须预先存在，属于当前用户，权限为 0700，采用规范绝对路径且没有符号链接；实际日志采用 FileJournalStore 的私有文件、锁、CAS、fsync 和归档规则。服务端为发布/Actor/原请求或取消请求派生固定命名空间。浏览器不能指定日志路径、RPC、发布或密钥。

服务仅绑定 127.0.0.1。HTTP 校验实际本地 Host；原生 POST 还要求完全相同的 Origin、JSON 和同源 fetch 元数据，禁止查询参数与未知动作。此服务用于可信本机的单用户操作，不提供公网多用户托管隔离。公开配置只展示发布身份和 RPC origin，省略提供商路径、查询凭据和本地日志路径；传输错误也经过脱敏。

钱包链名由受信任发布的网络身份映射。明确本地测试映射为 `solana:localnet`，已识别主网身份映射为 `solana:mainnet`；未知网络不猜测链名，钱包连接及签名保持关闭。配置展示不等于网络已经验证，SDK 会在准备、模拟、发送等路径核对实际 genesis 与原生配置。真实目标钱包的 v1 支持仍须单独验收。

## 精确步骤与恢复

1. 输入明确 Actor 和 intent。nonce、金额及优先费等 u64 用规范十进制字符串，payload 用小写字节 hex；资源预算明确给出。控制台不自动递增 nonce。
2. 准备后检查 Actor、nonce、费用支付人、全部必需签名人、资源预算、请求哈希、消息与有效期。公开 envelope 可以导出或重新导入；服务端始终按固定发布重建检查。
3. 明确点击模拟，通过后才能签名。钱包必须在实际 `solana:signTransaction` 接口声明数字版本 1、支持配置网络且授权当前账户。控制台只请求签名，把 exact unsignedHex 交易字节交给钱包，不调用钱包的发送接口。多签可导入完整签名交易，SDK 在发送前核验原消息及所有必需签名。
4. 明确点击发送。签名仅驻留内存；发送尝试后即清除，禁止静默重发。RPC 接收是 PENDING，响应丢失是 UNKNOWN，均不能显示为业务成功。
5. 查询同一 Actor/nonce 的 finalized 结果。需要更新有效期时只刷新同一 Frame/nonce，清除旧检查、模拟和签名，然后重新完成各步骤。输入变化或过期异步响应不能恢复旧签名。
6. 显式另签取消请求使用独立 cancellation 日志与同一 nonce 的 SYNC，原请求完整保留；竞争结果以实际账本为准，不能撤销已经执行的业务。取消预算变化会使正在准备的旧取消请求失效，包括第一份取消 envelope 尚未返回时。

## 验收范围

桥接测试使用真实私有 FileJournalStore、受限 finalized 模拟 RPC 和公开测试签名；HTTP 测试检查 Host/Origin、字段、大小、UTF-8、错误脱敏与默认禁用；控制台测试覆盖真实事件绑定、逐步门禁、字节一致、双日志、失联 UNKNOWN 和异步竞争。独立只读复查发现的取消预算竞态已修复并回归。

实际本地浏览器已确认第四页、默认禁用状态、检查/模拟/签名/发送按钮及查询恢复区域；返回构造页后 C320 完整实验仍为 PASS 73/73、q2。没有请求真实钱包、签署用户交易、访问真实 RPC 或部署合约。启用态的真实钱包兼容与批准网络复现仍是发布验收条件。

高级控制台不等于完整新手操作流程。P10.2a 已增加第五页的购买与已知作品/历史权益规划，并显式交给此控制台；项目创建、制造、跨层合成、K-aware 退出等引导仍未完成。当前范围见 [P10.2a说明](GUIDED-OPERATIONS.md)；后期生态世界不属于本模块。
