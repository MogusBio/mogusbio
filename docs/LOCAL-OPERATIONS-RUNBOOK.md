# BioLab 本地首版运行与恢复

本机实现与生产发布分别验收。当前不加载正式配置，不连接真实钱包，不部署或发放真实资产。项目根目录是独立的 `biolab/`。

## 启动与验证

在本目录执行 `npm test`、`node scripts/freeze-func2.mjs`。`npm start`启动127.0.0.1:4317；停止时使用启动终端的Ctrl-C。网页未设置固定发布配置时，链上功能默认关闭，本地设计和实验可用。这不是公网多用户服务的部署方式。

十个页面依次是构造、玩家路径、经济表、原生交易、资产购买、项目发售、库存制造、逐层合成、持续挖矿、首创研究。所有生成的交易意图只填写第四页；玩家仍须明确准备、检查、模拟、签名、发送和查询。模拟、发送回执或本地实验PASS均不单独证明成品或收益到账。

## 普通玩家链

1. 创建实验室项目，固定四类原料的价格、项目额度及销售收款人。实际创建记录核验后取得项目ID。
2. 按实际价格和全网额度购买AA、NUC、LIPID、SUGAR标准单位。购买只交付原料，不制造Source或挖矿资产。
3. 用真实库存建立部件制造清单，按实际上传、封存和制造状态继续。保存Actor及workflowID；输入变化不暗中改变旧Source编号。实际Root出现后才提供资产交接。
4. 部件即可普通质押。等待实际生效和闭合小时后，全局逐步推进、本人按历史顺序计债、累计领取。未领取债权不是可直接支付的LAB余额。
5. 升级前完整退出输入，等待普通/K结束边界并完成本人历史覆盖。清单绑定真实子Root及不可变子图；按实际V4阶段推进，全部73轮完成后FINAL。
6. 单向合成消费旧实例并生成一个新实例。历史旧债仍归原Position受益人，新成品需要单独质押；不会自动获得父子双份未来权重。

完整参考链是四类标准单位30/60/15/15→60部件→15细胞→6器官→1生物，功能模块尺度不对应现实中的细胞数量。真实本地链从零LAB开始，部件赚取48.083160LAB，升级销毁48LAB，生物两小时领取0.941780LAB，最终钱包1.024940LAB。这是具体历史条件下的记录，不是未来收益报价。

## 金额和费用

| 项目 | 核对口径 |
| --- | --- |
| 销售款 | 实际不可变项目价格×标准原料数量，付项目收款人 |
| 创建费 | 固定10,000,000lamports；单列实际账户押存和网络费 |
| 原料资源费 | 每标准单位100,000lamports，单列销售款 |
| 部件 | 首版无LAB制造费，仍烧实际原料并付实际账户/网络成本 |
| 细胞 | 每个0.8LAB，15个合计12LAB |
| 六器官 | 分别3.2/4.8/6.4/3.2/3.2/3.2LAB，合计24LAB |
| 生物 | 12LAB；上层完整链合计48LAB |
| maxRent | 原生分配上限，不能冒充实际租金、网络费或整笔总支出上限 |
| LAB收款ATA | 首次原子创建的押存可能位于原生maxRent之外 |
| 小时关闭 | 仅退实际记录余额给原开立者，不产生LAB或原料 |
| 失败交易 | 业务状态原子回滚；已包含交易仍可能支付网络费用 |

未接实际网络报价时，页面保持资金充足未验证。每小时一份全局快照，完整计债后可退原开立者押存；旧“每个成品每小时永久收据6.264SOL/天”已经废弃。

## 首创与恢复

普通挖矿不要求COMMIT。选择首创时，先保存私有设计与随机salt，保留同一个请求ID重试；实际COMMIT确认后在制造窗口公开上传。作者固定nonce窗口，指定独立推进者执行STEP，作者完成FINAL。中途使用作者nonce处理其他操作会破坏该窗口，不能用填充操作或自动改号修补。C310已经在旧16模型配置完成真实首创到领奖，现已公开；新OPEN310须在16必备模型之外增加第17个C310 K0，复制它只有普通资格。尚未确认仍未公开的C<310方案。

原始交易由耐久primary日志保存；取消竞争使用单独cancellation日志。失联保持UNKNOWN，先恢复旧请求，不新造一个“相同业务”请求。已确认归档与私有research文件应一起备份；本地目录权限700、文件600，恢复整份目录，不能编辑nonce、salt、清单或归档摘要。锁恢复必须证明原进程已死亡，不能按年龄直接删锁。

服务停机不会自动变更链上释放、抹除债权或给管理员补发权限。恢复后读取实际全局前沿与历史覆盖，逐步推进。公网认证、会话隔离和有界持续服务已经实现并做本地验收，见[运行规格](PUBLIC-SERVICE-RUNBOOK.md)。真实网络/钱包、持续负载、生产身份和有资金的实际服务尚未验收；独立安全审计按用户要求暂不安排。完整钱包发现不是本版已实现的能力。
