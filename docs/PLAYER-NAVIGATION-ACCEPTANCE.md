# 七入口导航整理验收

日期：2026-10-25。主站和本机测试账号已按同一用途整理成七个入口：协议数据、实验室项目、生物工坊、生物能、我的资产、交易市场、首创研究。主站交易市场展开原料／成品／生物三个子页；测试页三个分类有独立hash。

本轮是界面和导航整理。材料、科学模型、制造/合成、LAB经济、首创、账户权限、原生ABI和程序源码均未修改。生产市场与挂牌持续产出仍未实现，没有部署。

## 已完成的页面分工

| 入口 | 主站 | 本机测试账号 |
| --- | --- | --- |
| 协议数据 | 既有经济规则与算例 | 固定协议规则、当前本机账号状态 |
| 实验室项目 | 浏览与首发购料、创建与发售 | 当前测试项目真实购料；创建项目另开完整工作台 |
| 生物工坊 | 设计实验、制造部件、逐层合成 | 选择套装、真实模型制造与逐层合成 |
| 生物能 | 现有登记、结算、领取、退出等业务入口 | 唯一登记/退出卡片、推进测试时间与领取 |
| 我的资产 | 真实发现入口 | 可用原料、作品数量和只读资产摘要 |
| 三个市场 | 三个独立说明页，显式本机环境下可另开测试页 | 原料、部件/细胞/器官、完整生物买卖与上下架 |
| 首创研究 | 既有私有研究与竞赛 | 说明公开C310不算新首创，另开研究工作台 |

项目首发不再被命名为原料二级市场。原主站12个业务叶路由各保留一次，另加3个市场叶，共15个；七个父包装不冒用业务导航事件。主站353个旧ID完整保留，当前369个且无重复。测试页31个旧ID完整保留，当前54个且无重复。

`player-routing.js`负责固定白名单、标题、视图和当前分组；真实切页仍点击原叶一次，让原业务取消/权限/规划失效处理照常执行。主站市场本身没有新建交易；`market-panel.js`只GET公开本机能力，且只在明确的同源HTTP回环配置下显示测试链接。

主站与测试页的外部跳转均以新标签打开，不卸载当前草稿或未确认请求。测试内部只切现有面板，不能因切页重置、购买、消费、领取或改变所选套装。BIO工坊完成后先导航到生物能；同名作品显示套装名称与短编号。

## 验收结果

- 完整Node回归1008/1008通过，0失败：`evidence/unified-player-navigation-final-20261025.log`。
- 主站33项导航/草稿/权限/静态路由聚焦通过；25项实际挂载导航与本机接口聚焦通过；旧业务控制器88项通过。
- 第一轮完整回归1001/1008通过，7处失败均为旧测试写死12页。同步到15页后保留逐页独占、默认禁用、无自动交易和权限/恢复断言，最终全量通过。首轮日志保留，未覆盖。
- 14份数学模型身份保持不变；原生ELF及生产政策保持原身份，本轮没有新执行原生Bank交易。

实际1280×720浏览器验证：主站新市场深链只显示一页；未应用JSON跨成品市场切换后逐字保留。测试九个叶路由逐个进入，LAB和SOL不变，输入框数量为0，无横向溢出。

从实验室项目购买120份原料，工坊制造60→15→6→1，进入生物能登记，推进/领取/退出与最后领取，升级销毁48 LAB，两次领取共0.941780 LAB，余额1.167620。再走BIO挂牌/取消、买一份AA→资产页显示31份、刷新保留原路由和账目。最后明确重置到60部件、120份备用原料、48.225840 LAB，交付用户继续点击。两页面console错误记录为空。

窄屏覆盖为结构与响应CSS检查，本轮没有物理手机或真实窄窗口验收；不把历史旧界面截图复用为本轮证明。正式钱包、RPC、签名器与生产运行环境仍按原清单单独验收。
