# 本机点击体验指南

更新：2026-10-26。**当前测试账号里的构造路径是“公开 C310 参考样本的快捷体验”，不是已经完成的逐件自由构造工坊。** 一次出现60个部件，是参考任务批量执行60次制造；玩家在这条路径中没有逐件设计，也没有提交自己的构造图。逐件制造与自由设计的已有能力、测试入口缺项见[构造模式与差距](CONSTRUCTION-MODES-AND-GAPS.md)。

已有本机服务时，直接打开 [BioLab 测试账号](http://localhost:4318/test-lab)，点击「进入测试账号 →」。不用密码、钱包、地址或手填实例编号。

需要自行启动时，在 `biolab` 目录使用 Node.js 22 或更新版本；首次安装依赖运行 `npm ci`，之后启动：

```sh
node scripts/preview-discovery-local.mjs --local-public-fixture --playtest
```

等待终端显示服务地址后再打开页面。首次准备模型账本需要一些时间；同一端口已有服务时无需重复启动。

## 开始时有什么

| 数据 | 初始数量与用途 |
| --- | --- |
| 备用原料 | AA 氨基酸 30 份、NUC 核苷酸 60 份、LIPID 脂质 15 份、SUGAR 糖类 15 份，共 120 份 |
| 预备参考样本 | 60 个启动前按固定规则制造、可继续合成的功能部件；不是玩家刚刚设计完成的60件作品 |
| 测试 LAB | 48.225840 LAB，由预备部件在 HOST 参考模型中的历史质押、结算和领取产生 |
| 测试 SOL | 支付本机模型中的购料、账户准备和市场成交；具体余额看页面 |

备用原料与预备部件是两份独立库存。启动准备先购入两套原料，再用其中一套逐件制造这60件参考部件，按本地模型结算历史收益、退出并领取升级费用，另一套120份原料仍可用。这是隔离测试账本的预备历史，不能显示为玩家本次亲手完成的步骤。

四类原料按份直接制造；合成消耗旧实例，不开包、拆解或回收。套装只是方便选择的一组作品，实际是否可用仍按当前材料、所有权和锁定状态检查。

## 按参考样本快速完成一条构造链

进入后左侧分七个入口。想复现固定样本，先到「实验室项目」点「按样本用量购买120份原料」，再到「生物工坊」跟随「样本下一步」；新套装会自动选中，材料和编号自动带入。工坊已明确标出C310与批量数量，也可从样本备料步骤开始。

工坊只处理构造；构造完成后点「前往生物能」，在独立页面管理登记、领取和退出。「我的资产」只读展示原料与作品；三个市场从左侧「交易市场」分类进入。页面切换和刷新保留所选套装、已存进度及原未确认请求。

| 按钮与结果 | 本步测试 LAB 合成费 |
| --- | ---: |
| 购买一套 120 份四类原料 | 购料支付测试 SOL，页面账目显示实际变化 |
| 按固定原语批量制造 60 个参考部件 | 无 LAB 合成费 |
| 按 C310 参考图逐项验证、批量合成 15 个功能细胞，消耗这套 60 部件 | 12 LAB |
| 按 C310 参考图逐项验证、批量合成 6 个器官，消耗这套 15 细胞 | 24 LAB |
| 按 C310 参考图验证并合成 1 个完整生物，消耗这套 6 器官 | 12 LAB |

整条新构造链消耗 120 份原料和 48 LAB；原来的备用原料仍按实际库存显示。也可以选择预备部件套装，直接从细胞开始。升级采用单向合成，已消耗的旧作品不会继续登记产出。

这里的“快速”只合并操作入口，不免除账本消费：60部件由15组×4类固定部件逐件制造，细胞和器官也逐个调用同一合成验证与消费模块。任一子步骤失败，整个本次快捷操作回滚；没有凭空增加成品。它执行的是HOST参考模型，不是60笔已广播的Solana交易。

这条路径固定使用公开 C310 构造，展示普通持续产出流程；不是玩家原创，也不是新的首创。测试接口当前只接收所选套装等标识，不接收玩家自定义构造图。展开「查看本次材料和 LAB 对账」可以核对每步库存、余额和合成销毁。

### 想自己一件件构造时

主站「生物工坊」已有三个独立模块：设计实验、制造部件、逐层合成。制造清单每次针对一个固定部件；合成清单每次针对一个细胞、器官或生物，绑定实际输入与玩家设计图，经验证后才消费输入。操作还需实际配置、库存、权限、费用与明确签名。

当前测试账号没有把这些模块接成同一测试库存上的逐件自由流程，不能把参考批量按钮改名就说已经实现。工作台可编辑的自由度是冻结模型内的连接、比例、能力、布局及层级模式；F1部件仍为固定原语，不支持任意蛋白序列的创造、折叠预测和真实生物实验。

### 当前套装进度与“已体验”

本次审查发现，旧界面用全账户最近操作类型标“已体验”，没有按当前所选套装区分。因此在一套样本走完后切到另一套原料，也可能看到五步全部“已体验”；较早记录移出最近30条后，标记也可能消失。这不是当前套装已逐件完成或已自由设计的证明。

进度应以当前套装阶段标“已到达／当前／未到达”，预备数据明确标“预备参考样本”；全账户账目仅作历史记录。导航、改文案及修正进度显示不应重置测试数据，也不改变当前库存、作品、余额、请求编号或未确认操作。

## 登记、领取和退出

1. 进入「生物能」，在成品卡片点「登记产出」。部件、细胞、器官、生物都可按实际条件登记；刚登记时先显示待生效。
2. 点「推进 2 个测试小时」，让开始边界生效并产生一个完整小时的结算结果。这里推进的是测试时间，无需真实等待。
3. 点「领取已赚 LAB」。只有已结算的实际债权能领取；金额随作品和全网模型状态变化，不是固定日产承诺。
4. 点作品的「退出登记」，再推进到页面提示的下一小时结束边界。退出预约不会立即解除锁定；生效前不能用它合成或挂牌。
5. 最后再领取剩余收益。退出不抹掉历史收益，转让后旧收益也仍归原固定受益人。

## 三个市场

「原料市场」交易四类现有原料；「成品市场」交易部件、细胞和器官；「生物市场」交易完整生物。页面采用固定测试报价、零测试成交手续费，不代表正式市场定价。

- **购买**：点「购买这件商品」，测试 SOL 与原资产一起交付。原料进入可用库存，成品进入作品列表；市场不增发原料。
- **出售**：原料点选挂牌份数，作品点「挂牌这件成品」。挂牌后资产进入托管，不能重复制造、合成、登记或挂牌。
- **取消**：点「取消挂牌」，退回同一批原料或同一件作品，不产生销售收入。
- **模拟成交**：点「模拟测试对手购买」，由明确标注的测试交易对手付款并取得资产。它不是其他真实玩家，也不代表真实流动性。

新账号的市场先有测试对手的原料和部件。完成高级构造并挂牌后，可切换对应市场测试器官或生物出售。当前本地先行模式要求已登记或退出尚未生效的作品先完成退出；出售作品不转走原受益人的历史债权。这不是TAPE挂牌期间继续挖矿的同等规则，正式市场的连续产出与成交切分还需实现。所有一键参考作品均为普通产出资产，首创权益交易未开放。

## 重试、保存与重新开始

- **按钮执行中**：等本次结果返回，其他写操作会暂时禁用。
- **显示「继续上次点击」**：优先点它，按同一操作编号核对未知结果，避免新建重复操作。不要用重新开始绕过未确认的操作。
- **刷新状态 / 刷新页面**：读取已保存的进度。服务器重启后，只要保留本机测试数据目录和同一浏览器的会话 cookie，也能恢复账户。未确认点击的自动恢复还依赖该标签页的会话存储。
- **重新开始**：明确放弃当前测试进度，从预备数据开启新一轮；旧请求不能在新一轮重新执行。它不是材料回收或收益退款。

测试数据由本机服务保存于 `.data/playtest/`。不要把清除浏览器数据、删除该目录或更换端口当作正常的进度恢复步骤。

## 范围与检查记录

这是 HOST 参考模型的本机交互体验，执行既有协议模块的材料、功能和奖励计算。预备样本和参考快捷构造不代表逐件自由工坊已经完成。没有连接真实钱包、发送交易或验证本轮 native 执行；三个测试市场也不是公网正式市场。正式市场的托管、付款与转移原子指令仍需独立实现和验收。本地通过不保证不存在未知问题。
