# Composition modules

Dependency-free ESM lifecycle implementation for direct material manufacture and one-way, layered synthesis. It reuses protocol-core byte/material/atomic helpers, biology graph validation, and settlement guards. Run:

```sh
node --test biolab/packages/composition/test/*.test.mjs
```

`artifact.mjs` implements the fixed 256KiB maximum, exact1024-byte aligned chunks (short final chunk), sequence CAS, same-length replacement while WRITING, complete ordinary SHA256 seal, immutable SEALED bytes and the exact131-byte fixed body prefix. Preparing or sealing data never creates an asset, a quality certificate or mining rewards.

`payload.mjs` implements the exact BIOP7D01 header and Graph Vec / Direct74 / LeafMap70 / capsule Vec encoding. It enforces canonical order, complete positions, distinct actual instances, bounds, exact full-byte fingerprints, and trailing-byte exhaustion. Source union checks include both effective and retired historical slices, reject any overlap, and merge only adjacent effective slices for the canonical union hash.

`coordinator.mjs` owns actual manufacturing paths:

| API | Behavior |
| --- | --- |
| `createCompositionCoordinator(base, trustedDependencies)` | Captures approved domain/config/rule/validator/LAB Mint and server-owned verifier dependencies; never accept these functions from a player request |
| `initialState(materialState, clockConfig)` | Trusted deployment bootstrap only; creates composition maps and the settlement snapshot |
| `manufactureComponent(state, context)` | Parses actual501 frame and material plan; runs exact core BOM/current Source prefix consumption; creates one fixed descriptor q1/B120000 root with complete original debit plan; no LAB protocol fee |
| `prepareSynthesisPayload(state,{graph,inputIds})` | Builds a reviewable payload from actual stored independent inputs; does not consume or certify them |
| `synthesize(state, context)` | Parses actual702 frame, reads immutable sealed payload, re-derives all actual inputs/leaf capsules, rechecks child graphs and historical source union, executes trusted functional/semantic verifier, checks source wallet funds, burns the original fixed LAB fee, consumes all direct inputs and creates output atomically |

All preparation functions return `{state,result,...}` with a detached draft and never mutate the supplied state. An outer protocol-core `executeAtomic` must commit the returned draft and sole actor nonce together. Native AccountInfo/PDA/signature/rent/SPL Token validation is still the adapter's responsibility. `authorizedActors` and material owner sets are trusted ingress evidence, not a signature generated by this JavaScript package. `actualRentLamports` must come from that adapter; passing0 in host tests does not prove zero rent on Solana.

The callback contract for `verifyFunction(graph,{challenge})` uses integer ppm (1000000 or2000000) and is deliberately strict:

```text
status: "PASS"
q_ppm: BigInt, 1000-quantized, requested challenge <= q <= 2000000
graphSHA: exact32 bytes
transcriptSHA: exact32 bytes
positiveBitmap: exact64 bytes, all bits above actual edge count zero
taskApplicable: boolean matching the frozen BIO/q2/tier/v task conditions
C: BigInt, positive for task-admitted BIO and zero otherwise
```

Fixed hard-support targets3/9/14/15/21 require challenge2000000 and legitimately return q1000000; that exception is checked explicitly. COMMON tiers are allowed when the real cut/capacity validation passes. FUNC2 reports use suite2/fixture1/load1 and produce the exact typed H16 from real root/graph/leaf-map data.

Missing traces/bitmaps, a boolean, a player's claimed PASS, or `MODEL_PASS` without a complete certificate are rejected. The semantic callback must produce the actual frozen canonical design ID. A task-admitted BIO additionally requires the trusted knowledge admission hook; absence refuses the entire synthesis. No K is granted merely because a root was made. COMPETE requires the trusted originality hook and an exact commit/salt tail; no hook rejects it. All partial/q1 results also invoke the hook when connected, preserving original disclosure.

Only layer-specific direct inputs are allowed: a CELL consumes B/E/I and its exact role's S; each ORGAN consumes its fixed cell-role set; BIO consumes all six actual organs. Parent graphs preserve each manufactured child's graph exactly. Historical component source plans are re-parsed from immutable original capsules, not trusted cached effective lists. Transfer/active-stake state comes from the settlement root; ended and fully materialized old positions keep their original beneficiary after input consumption.

**The full lifecycle test uses explicit verifier module mocks to isolate lifecycle/economic behavior.** It does not constitute biological function, formal transcript/H16, canonical novelty or SBF acceptance. Production admission remains false. Real functional verifier/canonical/task integration, bounded-memory streaming, native atomic Token CPIs, exact root PDA/rent/transport and independent security review must pass before deployment. Full-state JavaScript cloning and in-memory source sorting are reference algorithms; they are not claims of fitting Solana's heap/CU limits.
